Quick Troubleshooting

Start with the basics

A few simple checks can help identify the source of a game problem.

01

Check your connection

Make sure your internet connection is working normally when downloading or updating a game.

02

Restart the application

Close the relevant game or application completely and try again.

03

Check available storage

Insufficient disk space can interfere with downloads and installations.

04

Record the error

Note the exact error message before contacting official support.

Questions & Answers

Helpful answers

Here are some general answers to common Big Fish Games support questions.

Why won't my game start?
Restart the computer and try opening the game again. Check for available updates and make note of any error message. If the issue remains, consult official support.
What can I do if a game download stops?
Check your internet connection, available storage space, and whether the application is up to date. Then retry the download.
What information is useful for account problems?
Be ready with the email associated with your account and a description of the problem. Never provide your password to anyone.
What should I do when a game displays an error?
Record the exact error message and when it occurs. Restart the application and check for updates before seeking further assistance.
Where should I go for official assistance?
For account, purchase, billing, or product-specific matters, use the current official Big Fish Games support resources.

Need more assistance?

If basic troubleshooting does not solve your problem, use the official Big Fish Games support resources for further assistance.
